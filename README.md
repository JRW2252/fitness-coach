# Cycling Coach

An evidence-based, exercise-physiologist-level cycling coach built as a Claude skill.

## Contents
- `skill/SKILL.md` — the coaching skill: zones, intensity distribution, workouts, periodization, strength, bone health, durability, heat, fueling, supplements, illness return, masters athletes, adherence, check-in rules, red flags, and a PubMed evidence base with DOIs.
- `tracker/TRACKER.md` — layout and formulas of the daily/session/weekly/test check-in tracker the coach reads to adapt plans.

## Using the skill
Add `skill/SKILL.md` as a skill in Claude (or drop the `skill/` folder into a Claude Code skills directory as `cycling-coach/`).

## Disclaimer
Coaching guidance, not medical advice. The skill tells athletes to stop and see a physician for red-flag symptoms.

Evidence sourced from PubMed (see DOIs in `SKILL.md`).
